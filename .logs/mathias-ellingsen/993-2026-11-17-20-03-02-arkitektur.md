# Arkitektur

## 2026-11-17 kl. 20:03 — Mathias Ellingsen

### Oppgave
Lage arkitekturen for PROGNOS v1 med `bmad-architecture`. Grunnlaget var prd.md, addendum.md, DESIGN.md, EXPERIENCE.md, issues.md, beslutningsloggen, teknisk.md og arkitekturutkastet. Arkitekturen skulle løse H6 (total WAPE og tall som kan regnes etter), få med faktisk, P10, P50 og P90 per modell og opprinnelse til detaljtabellen, og rette de 5 punktene der utkastet var utdatert. Rammene var SQLite, ingen Docker, bare statsforecast og norsk språk.

### Plan
- Coaching path. Leveransen var spine-dokumentet og en forklaring for sensor i markdown. Utkastet skulle få en merknad om at det er erstattet.
- To runder med valg: paradigme, H6-modell, avrunding og skjema, deretter API-form, typekontrakt, kjøring og navngiving.
- Sjekket versjonene mot PyPI og npm, og proxyTimeout i kildekoden til next@16.4.6.
- Reviewer-porten: lint og fem subagenter (avstemming mot PRD, avstemming mot UX og logg, rubrikk, verifisering, adversarial), deretter retting.
- Oppdaterte kildene oppstrøms etter godkjenning, skrev forklaringen for sensor og språkvasket den med `bmad-review`.
